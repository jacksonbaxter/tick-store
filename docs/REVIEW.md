apiece (A to F), given the code and the format documents but not the authors' notes, and wrote
down what they found with how to show it failing and the smallest fix they would accept. Every
finding is either fixed, with a test written first and seen failing for the reason the finding
gives, or closed with its reason. A finding shown wrong is closed with the evidence and no code
change. File and line are at `ca96b36`; the commits are on top of it.
