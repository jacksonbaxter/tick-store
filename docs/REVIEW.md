Phase 4 opened with an independent review. Six reviewers each read the tree at `ca96b36`, one area
apiece (A to F), given the code and the format documents but not the authors' notes, and wrote
down what they found with how to show it failing and the smallest fix they would accept. Every
finding is either fixed, with a test written first and seen failing for the reason the finding
gives, or closed with its reason. A finding shown wrong is closed with the evidence and no code
change. File and line are at `ca96b36`; the commits are on top of it. The R- rows are a second
reviewer's pass over the codec and store fixes, read at `eac0adc`, and each says so beside its
file and line. The RA- rows are a second reviewer's pass over the ITCH and bench fixes, read
at `381c738`, and the RD- rows another's over the harness fixes and the query fuzz oracle, read
at `c804d77`; each row says which beside its file and line. The RF- rows are a second
reviewer's pass over the comparison protocol fixes, read at `ab57c83`, and say so the same way;
the RR- rows are the same reviewer's notes on the RA and RD fixes, read there too.
